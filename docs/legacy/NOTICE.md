# Arquivo histórico — não usar como evidência

Os scripts, README e gráficos originais documentam o estágio anterior do projeto.
Eles contêm vazamento por reamostragem antes do split, seleção usando toda a base,
CV em dados já reamostrados e AP calculada a partir de rótulos. Os scripts foram
arquivados como texto para não executarem por engano. As figuras PNG antigas em
reports/ também são históricas. Resultados válidos do protocolo corrigido ficam
em reports/metrics e reports/figures; não são diretamente comparáveis aos antigos.
